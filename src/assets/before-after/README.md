# Before & after photos

Put real photos from our jobs here. Name each pair:

    <service>-<number>-before.jpg
    <service>-<number>-after.jpg

<service> is one of: end-of-tenancy, deep, airbnb, office, post-construction, regular, general, oven, carpet

Examples: oven-1-before.jpg + oven-1-after.jpg, carpet-2-before.jpg + carpet-2-after.jpg

- Take both photos from the same spot and angle.
- No people's faces, house numbers or personal items without the customer's permission.
- Run `node scripts/shrink-images.mjs` before committing so the photos load fast on phones.

They appear automatically on the homepage and on the matching service page.
